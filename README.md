# 现代计算系统结构与算力技术

**开课单位：浙江科技大学自动化与电气工程学院**

**英文名称：Modern Computing Systems Architecture and Computing Technology**

## 课程简介

本课程围绕现代计算系统的结构、性能与算力组织展开，从冯·诺依曼架构和指令执行过程出发，逐步介绍指令系统、处理器微体系结构、存储层次、并行计算、GPU 与异构计算，并进一步延伸至数据中心、智能算力基础设施和新型计算架构。

课程强调从系统整体理解计算性能：既关注处理器内部的数据通路、流水线和动态调度，也关注数据在 Cache、主存、互连和加速器之间的移动成本。通过理论讲授、问题分析和实验验证，引导学生建立“计算—存储—通信—能效”协同分析的系统观。

## 课程目标

完成课程学习后，学生应能够：

- 理解指令集体系结构与微体系结构的基本关系，掌握现代处理器执行指令的主要过程；
- 分析流水线、乱序执行、分支预测和存储层次对系统性能的影响；
- 运用 Amdahl 定律、局部性、并行效率等基本方法解释常见性能现象；
- 理解多核处理器、GPU、专用加速器和异构计算系统的结构特点与适用场景；
- 通过实验获取性能数据，识别计算、存储和通信瓶颈，并形成有依据的优化结论；
- 了解数据中心、智能算力基础设施及新型计算架构的发展方向。

## 主要教学内容

| 模块 | 主要内容 |
| --- | --- |
| 计算系统概述 | 体系结构演进、性能指标、Amdahl 定律与冯·诺依曼瓶颈 |
| 指令系统与处理器 | ISA、数据表示、寻址方式、RISC-V 与处理器数据通路 |
| 流水线与乱序执行 | 指令级并行、流水线冒险、动态调度、分支预测与按序提交 |
| 存储系统 | 局部性、Cache、虚拟存储、地址转换与存储性能优化 |
| 并行计算与多核系统 | 任务并行、数据并行、同步、缓存一致性与性能可扩展性 |
| GPU 架构与编程模型 | SIMT、线程层次、存储组织、CUDA 编程与性能优化 |
| 异构计算系统 | CPU、GPU 与专用加速器的任务划分、数据移动和协同计算 |
| 数据中心与算力网络 | 集群组织、互连网络、资源调度与算力服务 |
| 智能算力基础设施 | AI 计算负载、加速平台、系统软件与端到端性能 |
| 新型计算架构 | 存算一体、近数据计算、绿色计算与未来发展趋势 |

## 教学组织

课程按 16 周组织教学，理论讲授、课堂研讨、实验验证和阶段复习相互衔接。前半程重点建立指令系统、处理器和存储系统基础；后半程逐步进入并行计算、GPU、异构计算和智能算力系统。课堂思考题用于检验关键概念之间的联系，参考答案用于课后对照和进一步讨论。

## 实验课程

课程设置六个实验项目：

1. RISC-V 指令与模拟；
2. 流水线与冒险观察；
3. Cache 行为与性能优化；
4. CUDA 并行程序入门；
5. GPU 归约性能优化；
6. 异构算力综合设计。

实验以“建立假设—获取数据—解释结果”为基本过程，要求学生在完成程序实现的同时，分析性能变化的原因，并说明优化方法的适用条件。
