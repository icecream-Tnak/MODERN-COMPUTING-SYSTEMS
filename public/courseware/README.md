# 课程 PPT 文件

将 PPT 文件放在此目录，并在 `app/course-data.ts` 对应章节中把 `available` 改为 `true`。

默认文件名如下：

1. `01-计算系统概述.pptx`
2. `02-指令系统与处理器.pptx`
3. `03-流水线与乱序执行.pptx`
4. `04-存储系统.pptx`
5. `05-并行计算与加速.pptx`
6. `06-GPU架构与编程模型.pptx`
7. `07-异构计算系统.pptx`
8. `08-数据中心与算力网络.pptx`
9. `09-智能算力基础设施.pptx`
10. `10-新型计算架构.pptx`
